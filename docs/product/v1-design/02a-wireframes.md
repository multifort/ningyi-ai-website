# 02A 核心页面低保真线框

线框用于确认信息层级和操作路径，不定义最终视觉风格。正式设计沿用官网的深蓝、亮蓝和青色体系，但产品页面以高密度、可阅读和状态清晰为优先。

### 关键状态

- 默认：约束折叠、无文件。
- 最低条件未满足：主按钮可点击但提交后定位缺失项，不逐字段制造红色错误。
- 已选择文件：显示本地文件名、大小和移除；不伪装为已上传。
- 点击开始：打开登录层，底层画布保持。

## 9. 移动端重排

- 入口画布纵向排列，三个上传区使用标签切换，不隐藏分类含义。
- 项目理解先显示概要和方向问题，来源以底部抽屉打开。
- 成果工作台使用“成果选择器 → 内容 → 来源/影响抽屉”，不强行压缩三栏。
- 复杂表格默认卡片化只读；允许筛选、查看详情、下载和简单字段修改。
- 任何“建议在桌面端操作”都不能阻止启动、查看状态、下载和删除。
