# 真实修改集验收

本目录保存 G2-04 的离线修改集。它不进入正式生成提示，只用于验证 R/C/S/P 影响规划、锁定冲突和无关变化率。

`BM-15-change-set.json` 基于 BM-15 的企业模板、报价、私有 MinIO、七类成果和成果包对象建立依赖图，覆盖：

- R：企业模板替换，只重渲染十类成果/成果包对象，模型任务为 0。
- C：税率变化，只重算含税总额、执行报价检查并重渲染报价和成果包，模型任务为 0。
- S：私有 MinIO 需求变化，只传播到对应功能、方案/实施/风险章节及相关成果；锁定功能会截断传播并形成冲突。
- P：项目方向重构，重建项目模型、全部语义章节与十类成果/成果包对象。

每个案例使用 80 个稳定对象作为无关样本，要求受影响目标召回率不低于 95%，计划和实际无关变化率均严格低于 2%，锁定对象变化数为 0。自动测试还注入 2 个无关变化，确认超过 2% 的漂移会被质量门阻断。

局部章节重生成、越界候选拒绝和历史版本回退继续由 `scripts/product-project-model-state.test.mjs` 使用隔离数据库验证；本目录补充的是跨 R/C/S/P 的固定修改输入和量化证据。
