# SPIKE-12：删除任务链与备份防复活

1. 接受方案删除或账号注销请求时同步撤销访问，旧下载链接立即失效。
2. 按顺序写主数据墓碑、清理对象存储、清理解析/成果派生数据、匿名化必要运行日志、登记备份墓碑并验证缺失。
3. 每一步幂等且可重试；对象存储短暂故障不会恢复访问权限，也不需要人工处理正文。
4. 账号注销只遍历该账号拥有的方案，不影响其他用户。
5. 备份恢复先加载删除墓碑，跳过已删除方案及其文件，避免数据复活。
6. 孤儿清理只处理私有前缀、数据库无引用且超过宽限期的对象；不扫描或删除公开网站资产。

备份介质的物理过期按基础设施保留周期完成，但逻辑访问和恢复能力在删除请求时立即撤销。
