# SPIKE-09：需求画布与登录衔接

- 登录前由浏览器保存结构化字段、随机 `draft_id` 和本地文件展示信息；文件内容不上传、不写数据库、不进入公开目录。
- 点击“开始生成方案”只检查“主要用途 + 描述或内容材料”两个最低条件，然后打开登录层，底层画布保持不变。
- 用户名密码登录或注册失败不清空字段和文件选择。
- 登录成功使用一次性哈希凭证原子绑定草稿与产品用户，自动创建内部方案标识；重复网络请求幂等，其他用户不能接管。
- 有文字描述时登录后立即启动快速理解，同时后台上传文件；只有文件时，在首个有效内容材料上传完成后自动启动。
- 刷新导致浏览器文件引用丢失时保留文字字段，并把文件明确标记为“需要重新选择”，不伪装成已上传。
- 用户始终只执行“填写/上传 → 开始生成 → 登录并继续”，没有新建项目、创建任务、选择模型或二次确认。
