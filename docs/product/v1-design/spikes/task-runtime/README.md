# SPIKE-07：无人化任务运行时

- 幂等键由项目、版本、任务类型、作用域和输入哈希组成；重复提交返回原任务，不重复扣费或生成文件。
- Worker 通过有限租约领取任务；进程崩溃或租约超时后任务自动回到队列，其他 Worker 可继续。
- 模型限流、超时、渲染超时和临时存储故障按指数退避自动重试。
- 质量门失败和结构化输出错误进入自动修复重试，不创建人工审核任务。
- 恶意文件、越权和输入契约错误直接阻断相关分支；无关成果继续执行。
- 正式模型内部预算不足进入 `deferred_budget`，不静默降级；预算窗口恢复后自动重新入队。
- 每次尝试独立记录 Worker、时间、错误码和输出哈希，日志不保存完整客户正文。
