# SPIKE-08：用户可见进度聚合

内部任务被收敛为六个用户阶段：理解信息、形成内容、一致性检查、生成文件、自动恢复和完成。界面不出现“新建项目”“跑任务”“选择模型”“Worker”等内部概念。

- 进度按内容 5、质量门 2、文件渲染 1 的工作权重计算，不用任务数量制造虚假进度。
- 七类成果独立聚合；某项成果完成后立即开放在线查看和对应格式下载，不等待整个成果包。
- 模型限流、超时和内部预算等待显示为“系统正在自动恢复”，`requiresUserAction=false`。
- 上游修改造成的局部失效显示为“受影响”，已经完成且无关的成果继续可用。
- 只有不可自动恢复且没有任何可用成果时才显示阻断；失败范围不会伪装成整体失败。
