# SPIKE-02：长文档章节状态账本

`section_ledger.py` 将长文档拆为有依赖关系的章节状态机。每章记录上下文包哈希、模型能力槽位、内容哈希、连续性摘要、引用来源和输出规模。

`quality_gate.py` 在章节进入 `validated` 前检查引用覆盖、上下文越界、范围越界、冲突遗漏、跨章节重复和规范术语。错误会阻止章节通过；重复和术语问题先作为自动返修提示，不引入人工审核节点。

核心规则：

- 同一时间只允许一个章节处于生成中。
- 依赖章节未通过质量检查时，后续章节不能开始。
- 中断后通过 `resume` 返回首个可继续章节和依赖摘要。
- 修改已完成章节时，只将传递依赖它的章节标记为 `stale`；无依赖章节不受影响。
- 状态账本不保存整章正文，只保存内容哈希和短摘要；正文进入成果版本存储，避免账本膨胀。
- `modelSlot` 记录能力档位而非供应商模型名，免费分析和正式生成可使用不同成本档位。

初始化示例：

```bash
python3 section_ledger.py init \
  --outline ../../benchmarks/BM-01/expected/solution-outline.json \
  --project-revision-id 62000000-0000-4000-8000-000000000001 \
  --output /tmp/section-ledger.json
```
