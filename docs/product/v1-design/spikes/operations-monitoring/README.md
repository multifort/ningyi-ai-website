# SPIKE-13：无人化运行监控与自动处置

- 只聚合匿名运行 ID、状态、耗时、用量、错误码和能力槽位，不采集客户正文、文件名或手机号。
- 核心指标包括成功率、完整成果自动交付率、端到端 P50/P95、积压数与最老等待、重试率、成本偏差和供应商失败率。
- 供应商异常只切换到通过同一基准门槛的备用候选；不存在已验证备用时暂停相关正式任务，不使用未验证或便宜模型顶替。
- 成本异常先限制免费分析并延迟新的正式任务，已经启动的正式任务保持质量槽位；禁止静默降级。
- 积压触发 Worker 扩容，质量或交付率异常暂停灰度扩张并保持旧版本。
- 小样本不触发成功率/交付率告警，避免刚启动时因统计噪声反复切换。

生产阈值通过配置维护，并以连续无人值守基准和实际供应商账单校准。
