# SPIKE-11：私有文件访问与短期下载

- 原始材料、解析中间件和成果文件只允许使用 `private/{user_id}/{solution_id}/...` 对象 Key，不进入 `public/`。
- 每次上传、读取、下载和删除同时校验已登录用户、方案归属和文件归属，不能只凭文件 UUID 或对象 Key 访问。
- 下载凭证使用 HMAC-SHA256，绑定用户、方案、文件和过期时间；最长有效期 5 分钟，服务端只记录 token 哈希。
- 验证签名使用常量时间比较；篡改、过期、跨用户复用和跨方案复用全部拒绝。
- 用户删除方案时先把方案和全部文件标记为撤销，再异步清理对象存储；旧签名链接立即失效。
- 对象存储桶保持私有，应用授权通过后才代理下载或签发存储层短期 URL。
