# SPIKE-04：多成果复用与成本预测

`plan_deliverables.py` 将交付分成两层：

1. 语义模块只生成一次，例如项目理解、需求基线、功能架构、估算分类、实施叙事和方案正文。
2. DOCX、PDF、XLSX、PPTX 等格式从同一内容版本确定性渲染，渲染任务的 `modelCall` 固定为 `false`。

估算与报价中的公式计算属于确定性模块，不调用模型。修改模板、Logo、颜色、页眉页脚或输出格式只创建新的渲染版本，不创建内容版本，也不消耗生成 token。

成本报告同时给出优化成本与“每个格式各自重新生成”的朴素成本，用于量化内容复用率。数值采用内部加权单位，不代表供应商报价。
