# SPIKE-10：上传安全与资源限制

- 服务端按 magic bytes 和 Office ZIP 内部结构识别真实格式，不信任浏览器 MIME 或文件扩展名。
- 加密 PDF/Office、宏文件、损坏压缩包、扩展名伪装、超大文件和高压缩比压缩炸弹在解析前隔离。
- Office 包只检查中央目录和必要结构，不执行宏、不加载外部链接、不运行嵌入对象。
- 内容材料、企业模板和品牌素材使用不同允许格式；无效模板自动回退默认模板。
- 单文件失败只记录自身错误和可执行建议。存在文字描述或至少一个有效内容材料时，整体流程继续。
- 所有文件进入私有暂存区后先验证，再转入解析队列；失败文件不会进入解析 Worker 或模型上下文。
