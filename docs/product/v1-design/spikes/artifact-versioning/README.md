# SPIKE-06：成果产物与版本仓库

- 内容版本 `Vn` 冻结语义模块哈希；只有语义或确定性业务数据改变才创建新版本。
- 渲染版本 `Rn` 引用内容版本、模板版本和渲染器版本；换模板、字体、Logo 或文件格式不创建内容版本，模型调用固定为 0。
- 单个文件保存对象存储 Key、SHA-256、大小、格式、成果类型和可见性，不把文件写入公开目录。
- 客户包、内部包和归档包只能引用同一内容版本的文件；客户包自动过滤 `internal` 文件。
- 成果包组装前会校验当前纳入包的成果 `content_version` 必须一致；内容版本混用时直接阻断并提示等待重生成。模板、字体或格式变化只增加 `render_version`，不阻断同一内容版本的打包。manifest 记录统一 `contentVersion`，便于下载后核对。
- 发布采用候选版本切换；候选失败时旧发布版不变，回滚只切换活动指针，不删除历史产物。
- ZIP 和 manifest 组装是确定性任务，模型调用固定为 0。
