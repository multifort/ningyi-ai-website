# BM-09 会员服务平台

L2 基准，验证会员等级、积分入账、退货冲正、积分有效期、活动互斥和跨成果数字一致性。

## 输入

- `sources/membership-rules.pdf`：等级门槛、积分公式、入账与到期、审批和首期边界。
- `sources/campaigns.xlsx`：三项活动规则、四笔合成订单、公式结果和活动叠加冲突。
- `sources/member-page-spec.md`：会员中心展示、解释性信息、权限和禁止入口。
- `intake.json`：项目目标、预算、周期和成果偏好。

## 重点验证

1. 等级按前 12 个完整自然月已结算净额计算，不能用下单金额或自然年累计额替代。
2. 基础积分按订单级实付可积分金额向下取整，退货须沿用原订单与原活动规则复算。
3. 活动上限只限制活动积分；ORD-SYN-902 应为基础 2,200 分加活动 1,500 分，共 3,700 分。
4. 积分以实际入账年度为准，在次年 12 月 31 日 23:59:59 到期，不能按下单日或活动结束日计算。
5. 新客券和生日券互斥，新客券优先；双倍积分可与券并用，但券抵扣额不产生积分。
6. 人工调账须双人复核，超过 5,000 分增加负责人审批；首期范围不得被扩张。

所有会员、订单和活动数据均为虚构样例，仅用于离线验收。
