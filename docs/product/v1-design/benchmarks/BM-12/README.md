# BM-12 CRM 与 ERP 集成

L3 基准，验证接口冲突、主数据所有权、金额换算、幂等、错误恢复、部署隔离和可核对工作量。

## 输入

- `sources/crm-api-spec.pdf`：CRM 客户、报价、合同事件、认证、限流、幂等和错误处理。
- `sources/erp-api-spec.pdf`：ERP 客户引用、销售订单、履约财务状态、主数据和恢复规则。
- `sources/field-mapping.xlsx`：字段映射、主数据边界、金额样例、幂等冲突和失败恢复矩阵。
- `sources/integration-deployment.png`：CRM SaaS、集成平台和企业内网的部署与数据流。
- `intake.json`：项目目标、预算、周期和首期范围。

## 重点验证

1. CRM 拥有客户身份、商机、报价和签约事实；ERP 拥有客户财务属性、物料、税码、销售订单、发运、发票、应收和付款事实。
2. CRM SaaS 不得直连 ERP；请求必须经过网关、编排、消息队列和内网适配器。
3. `external_order_no` 永久唯一，幂等键保留 24 小时；超时结果未知时先按业务键查询，不能直接再次创建。
4. 金额按行从含税金额换算不含税金额和税额，保留原币并单独传汇率，不得在订单级重新分摊尾差。
5. 400、409 不自动重试；429 与 5xx 按 5 秒、30 秒、2 分钟、10 分钟退避，第 5 次失败进入死信。
6. INT-SYN-001—004 的金额、币种、幂等和冲突结果必须在所有成果中一致。

所有系统、地址、主体和交易数据均为虚构样例，仅用于离线验收。
