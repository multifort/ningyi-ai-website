# BM-08 经营数据看板

L2 基准，验证多来源经营指标的口径治理、公式追踪、同名指标冲突、数据时效、客户主键和权限边界。

## 输入

- `sources/metric-definitions.xlsx`：销售额、毛利率、客户复购率和库存周转天数的管理口径、公式与样例核对。
- `sources/current-dashboard.png`：现有运营看板截图，保留“销售额”同名不同义和数据延迟提示。
- `sources/data-source-notes.pdf`：数据源、批处理时效、客户归并、权限与首期范围说明。
- `intake.json`：项目目标、预算、周期和成果偏好。

## 重点验证

1. 必须区分管理销售额与运营订单金额，不得把截图中的 1,260 万元直接当作财务结算收入。
2. 管理销售额、毛利率、客户复购率和库存周转天数须按工作簿公式复算并保留来源。
3. 看板是 T+1 批处理，计划 08:30 完成；截图 09:05 更新，实际延迟 35 分钟，不得宣称实时。
4. 客户复购率以 CRM 统一客户 ID 归并；未映射渠道账号进入数据质量清单，不得直接按渠道账号计数。
5. 毛利与明细数据须按角色和区域授权；公开大屏不得展示客户标识、金额明细或毛利率。
6. 首期不建设实时流处理、不自动修复主数据、不替代财务系统，也不纳入寄售库存。

所有样例均为虚构数据，仅用于离线验收，不代表实际经营结果或系统承诺。
