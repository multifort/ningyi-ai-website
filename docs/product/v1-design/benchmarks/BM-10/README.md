# BM-10 合同管理系统

L2 基准，验证合同模板内容与项目需求的分离、累计审批规则、最小权限、用印版本锁定和完整归档边界。

## 输入

- `sources/software-service-contract-template.docx`：软件服务合同模板、字段分类和示例条款。
- `sources/approval-rules.xlsx`：金额审批阈值、叠加触发规则、样例核对、权限矩阵和归档期限。
- `sources/requirements-notes.md`：系统范围、模板治理、审批用印、权限归档和首期边界。
- `intake.json`：项目目标、预算、周期和成果偏好。

## 重点验证

1. 模板中的 30/60/10 付款比例、12 或 24 个月质保期和每日 0.03% 违约金均为示例或可选内容，不得直接成为项目默认值或正式承诺。
2. 占位字段、可选条款、标准条款、项目附件和示例数字必须分类处理，并保留正式合同采用的模板版本。
3. 含税总额低于 50 万元、50 万元至低于 200 万元、200 万元及以上分别进入确定的金额审批路径；恰好 50 万元和 200 万元不得落错档。
4. 金额、非标准条款、境外主体和跨境数据属于累计触发条件，不能只选一条路径；所有对外合同始终需要法务审核。
5. 全部审批完成并锁定版本后方可用印；印章管理员不能管理模板，经办人不能编辑已批准合同。
6. 签署后必须归档最终可编辑文件、签署扫描件、全部附件、审批记录、用印记录和版本链，并遵守 10 年、3 年、永久保存及法律保全规则。

所有主体、合同和审批数据均为虚构样例，仅用于离线验收。
