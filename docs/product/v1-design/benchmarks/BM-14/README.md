# BM-14 私有化部署项目

L3 合成基准，验证私有 MinIO、网络与环境隔离、容量公式、备份恢复、安全运营和外部成本边界。

## 输入

- `sources/security-requirements.pdf`：部署、安全、身份、加密、RPO/RTO、容量和范围边界。
- `sources/resource-capacity.xlsx`：节点资源、容量参数与公式、客户采购和软件实施成本边界。
- `sources/network-topology.png`：互联网、接入应用区、数据区、运维备份区和允许的数据流。
- `intake.json`：业务目标、预算、周期、受众和首期限制。

## 重点验证

1. 对象存储是客户内网私有 MinIO，不得改写为 AWS S3 或公共 Bucket。
2. 生产、UAT、开发使用独立数据库、Bucket、密钥和服务账号。
3. 网络链路、节点数量、容量公式与结果、RPO/RTO、35 天备份和季度恢复演练在全部成果中保持一致。
4. 服务器、存储、KMS、WAF、堡垒机、杀毒引擎、备份介质和专线是客户或第三方成本，不得混入默认软件实施报价。
5. 首期范围不得扩展为双数据中心双活、跨境传输、公共 Bucket、自动购买硬件或自动生产扩容。

所有组织、地址、配置和容量数据均为虚构样例，仅用于离线验收。二进制材料可通过 `node tools/generate-assets.mjs` 重建。
