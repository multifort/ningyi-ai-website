# BM-07 售后服务平台

L1 基准，验证工单状态、SLA计时口径、服务升级、来源追踪及对外成果可读性。

## 输入

- `sources/service-manual.docx`：状态、时限、服务边界和人工复核规则。
- `sources/work-orders.csv`：7条合成工单，包含自动回执、客户等待、跨工作时段和缺失联系人等边界样例。
- `sources/ticket-flow.png`：工单状态流转与P1升级路径。
- `intake.json`：项目目标、预算、周期和首期边界。

## 重点验证

1. 不能把自动回执当作首次人工响应。
2. 等待客户只暂停解决时钟，不能暂停首次响应时钟。
3. 生产停线按P1升级至服务主管。
4. 工单需客户确认后关闭；重开保留历史审计记录。
5. 缺少联系人及工作日历的数据限制要明确说明，不得臆造结论。
6. 生成的Word、Excel和PDF成果须内容完整、可打开且具有清晰层级，避免只堆叠文本或泄露内部标识。

所有样例均为虚构数据，不代表实际客户或服务承诺。
