# BM-02 OA 审批系统合成基准包

用于验证制度 PDF、金额矩阵 Excel 和流程截图共同输入时，系统能否区分确定性阈值、术语差异、异常流程与一期边界，并形成可追溯的七类成果。

## 输入

- `intake.json`：内部立项目标、目标用户、产品形态和范围约束。
- `sources/approval-policy.pdf`：审批制度、当前问题、权限、一期边界和验收指标。
- `sources/approval-matrix.xlsx`：采购与合同审批的确定性金额区间和角色映射。
- `sources/current-expense-approval.png`：现有费用审批界面与流程视觉材料。

所有组织、金额和流程均为合成测试内容，不对应真实企业。

## 重点检查

- 金额必须来自 Excel 数值单元格，不得由模型猜测或重算。
- “部门负责人/直属主管/部门主管”等称谓按映射合并，不误报为范围冲突。
- 退回、撤回、转交、催办和超时进入异常场景设计。
- 一期不得承诺合同电子签署、银企直连或自动付款。
