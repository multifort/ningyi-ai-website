# 先导基准准备计划

先准备四个项目，覆盖最小链路、流程/权限、综合多格式/模板和 AI Agent。材料全部使用合成内容，避免生产数据进入仓库。

## BM-01 中型企业 CRM

### 输入包

- `requirements.docx`：客户、联系人、商机、跟进、预测、权限和报表需求；含 2 条重复需求和 1 条范围外需求。
- `meeting-notes.pdf`：补充移动端期望、历史系统约束和一个与需求文档冲突的权限描述。
- `customer-sample.xlsx`：字段名称、脱敏样例、字段说明和数据质量问题。
- `intake.json`：主要用途为客户沟通，次要用途为估算报价。

### 黄金事实

- 首期范围为 Web 销售管理，不包含财务总账。
- 角色至少包括销售代表、销售经理和系统管理员。
- 商机关闭权限存在冲突，应进入方向选择。
- 核心链路为需求 → 功能 → 估算 → 方案 → 文件。

## BM-02 OA 审批系统

### 输入包

- `policy.pdf`：请假、采购和合同审批制度。
- `approval-matrix.xlsx`：金额、部门、角色和审批层级。
- `flow-screenshots/`：三个流程图，包含条件分支和退回。
- `intake.json`：主要用途为内部立项。

### 黄金事实

- 金额阈值来自 Excel，不由模型重新计算。
- 退回、撤回、转交和超时必须作为异常场景。
- 流程图和制度存在一个审批角色名称差异，应通过术语合并解决。

## BM-15 多格式与企业模板综合项目

### 输入包

- 需求 DOCX、扫描 PDF、历史 PPTX、功能 XLSX、CSV 和界面截图。
- 空白企业 `word-template.docx`、`estimate-template.xlsx`、`deck-template.pptx`。
- Logo、品牌色和字体说明。
- 至少一份含示例文字的模板，用于验证示例内容隔离。

### 黄金事实

- 七类成果全部生成，并形成三个成果包。
- 更换模板不增加内容版本和模型调用。
- 客户包不包含原始材料、详细来源、内部成本和利润。
- 解决方案不少于 2 万字，并完成中断恢复试验。

## BM-17 文档与方案生成 Agent

### 输入包

- Agent 任务说明、知识来源目录、文档样例和写作规则。
- Word/PPT 企业模板。
- 权限与数据留存要求。
- 正确/错误生成样例，用于评测审核能力。

### 黄金事实

- Agent 项目模型必须包含任务、知识、工具、权限、记忆、模型路由、评测、成本和失败降级。
- 不能把“生成文档”简化为单轮模型调用。
- 长文档和多格式成果使用统一内容对象。
- 未授权时 Agent 不执行外部发布或消息发送。

## 准备顺序

1. 冻结 Intake 与黄金事实。
2. 编写合成原始材料，不先写目标成果全文。
3. 生成文件后计算 SHA-256 并写正式 manifest。
4. 两人研发期交叉检查关键事实和禁止结论。
5. 保存 `benchmark_version=1.0`，后续只增加版本。
