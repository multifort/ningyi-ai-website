# BM-06 采购与供应商协同

本基准覆盖采购金额分档、询比价、单一来源例外、岗位职责分离、供应商资质生命周期、履约评分、ERP 边界和紧急采购审计。所有企业名称、编号、金额和制度均为合成数据。

## 输入材料

- `sources/procurement-policy.pdf`：采购制度原件，用于制度 PDF 解析验证。
- `sources/procurement-policy.txt`：与制度 PDF 内容一致的纯文本版本，用于 TXT 解析验证。
- `sources/supplier-register.xlsx`：供应商状态、评分、证照日期、风险线索和参与采购限制。
- `intake.json`：项目目标、预算、范围及约束。

## 关键验收点

- 报价阈值按制度准确分档；单一来源例外包含原因佐证与双负责人会签。
- 申请、采购审批、验收和付款审核相互制衡。
- 证照过期和低分供应商采取不同处置；历史记录保留，禁止规则不被扩大化。
- 平台与 ERP 的订单、收货、付款职责边界清楚。
- 紧急流程可补录且保留可审计记录。
- 正式内容事实可追溯至制度或台账来源，不能把供应商编号当作业务说明。
