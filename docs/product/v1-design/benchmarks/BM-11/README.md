# BM-11 企业门户

L2 基准，验证企业门户存量内容迁移、路由重定向、多角色发布、内容生命周期和分批实施计划。

## 输入

- `sources/portal-columns.xlsx`：六个栏目的存量数量、迁移决策、目标路由、责任人、审批要求和迁移批次。
- `sources/legacy-portal-home.png`：合成旧站首页截图，体现固定宽度、陈旧内容和治理元数据缺失。
- `sources/content-governance.docx`：角色职责、发布工作流、栏目规则、迁移决策、验收、回退和安全边界。
- `intake.json`：项目目标、预算、周期和成果偏好。

## 重点验证

1. 620 条存量内容必须完整分配为直接迁移 250 条、改写 30 条、离线归档 340 条，数量差异必须为 0。
2. 集团新闻、通知公告、业务板块、投资者关系、人才发展和关于集团的分栏数量不得串用。
3. 内容编辑、部门审核人、专业审核人、门户发布员和平台管理员必须职责分离；任何人不得审批并发布自己的草稿。
4. 投资者关系 54 条必须由财务与法务专业复核；紧急公告仍须保留编辑与独立审核两人。
5. 有替代页的旧地址使用 301；无替代页的离线归档地址仅在 SEO 与法务复核后返回 410，离线归档不等同删除。
6. P0—P4 实施批次、7 天观察期和恢复旧站只读入口的回退边界必须保留。

所有组织、内容、地址和迁移数据均为虚构样例，仅用于离线验收。
